用独立内容类型发布短内容（微博 / 说说），通过短代码、页面模板、小工具或可选的连载流展示；不依赖特定主题。

本文件是项目中文文档。提交 WordPress.org 官方插件库时，请使用同目录的英文 readme.txt。

== 简介 ==

MicroBlog 增加 `micropost` 内容类型，让短动态不与正式文章混在一起。每条微博都有独立固定链接（例如 `/microposts/123.html`）、归档页和 feed，也能用短代码、页面模板或小工具放到任意位置。插件可用于任何主题；KoneyGao 主题只额外提供可选的首页微博区块。插件自带「微博列表（插件）」页面模板，页面正文无需写任何短代码。

亮点

* 独立的 `micropost` 内容类型，URL 前缀可配置，并支持 REST。
* `[microblog]` 短代码：最新微博列表，带分页、摘要和单图 / 双图 / 九宫格自适应图片布局。
* 插件自带「微博列表（插件）」页面模板：在「页面属性 → 模板」里选择即可。模板自带「标题居中 + 时间 + 浏览次数」的头部，原样输出你的页面正文，再接微博列表，不需要主题写任何代码。
* 「微博」侧栏小工具，以及不必离开后台就能发布的「快速微博」仪表盘小工具。
* 模糊时间（「3 分钟前」）或固定日期格式，可选标题、头像与 RSS 链接。
* 可选连载（Liveblog）模块：给已发布的文章挂一条滚动更新流，文章列表提供四态显示列，并可按篇设置 10–300 秒自动刷新。
* 自动 / 浅色 / 深色色彩模式：主题输出 `data-color-mode` 时跟随主题，否则跟随访客设备。
* 完整国际化（文本域 `microblog`），自带简体中文语言包。

== 安装与启用 ==

1. 把 `MicroBlog` 目录上传到 `/wp-content/plugins/`，或在「插件 → 安装插件」中安装。
2. 在插件列表页启用。启用时会写入三组默认设置并注册重写规则。
3. 打开「工具 → MicroBlog 设置」，配置显示方式、日期格式、URL 前缀、每页条数与图片。
4. 新建页面，在「页面属性 → 模板」中选择「微博列表（插件）」（正文可留空）。**这是默认且推荐的方式**；`[microblog]` 短代码仍然保留，用于在其他文章或页面正文里内嵌微博流；也可以把「微博」小工具拖到侧栏。
5. 1.9.8 起插件会自动重建缺失的重写规则；若 `/microposts/...` 仍返回 404，再打开「设置 → 固定链接」保存一次并清理页面缓存。

== 配置要点 ==

* 设置位于「工具 → MicroBlog 设置」，分三组：微博（标题、日期格式、URL 前缀、每页条数、编辑器特性、feed 与灯箱标记）、常规（连载开关、色彩模式、微博List页面顺序、微博List单页背景）、连载（仅在模块开启后显示）。
* URL 前缀：1–20 位小写字母或数字，留空则使用 `microposts`；修改后会自动刷新重写规则。
* 「微博列表（插件）」页面模板是**默认的展示方式**，由本插件通过 `theme_page_templates` + `template_include` 注册，直接调用 `microblog_render_list()`（不经过短代码）；主题不提供、也不包装这个模板。
* 微博List页面顺序：「工具 → MicroBlog 设置 → 基础设置 → 微博List页面顺序」可选择页面正文在列表之前（默认）还是之后；仅对「微博列表（插件）」页面模板生效，短代码与小工具不受影响。
* 微博List单页背景：「工具 → MicroBlog 设置 → 基础设置 → 微博List单页背景」决定「微博列表（插件）」页面模板是否附带单页浅灰卡片背景。默认开启，并沿用 KoneyGao 的文章列表排版；关闭后为普通 WordPress 页面样式，没有卡片背景，列表使用插件默认排版。其他主题不受影响，短代码与小工具也不受影响。
* 开启卡片背景时，KoneyGao 下微博列表标题正常态为柔和灰、hover 态为深色，字号 16px、字重 bold。
* 开发者 filter：`microblog_page_content_before_list`（布尔）覆盖正文顺序，`microblog_page_background_enabled`（布尔）覆盖单页背景开关。模板不会往页面正文里注入任何内容。
* `[microblog]` 作为**可选短代码保留**，用于在文章或页面正文里内嵌微博流。可用属性：`null_text`（默认 `(none)`）、`use_excerpt`、`q`（附加 WP_Query 参数）。开启连载后，`[micro_liveblog endpoint="..."]` 或 `[micro_liveblog live_id="..."]` 用于渲染更新流。WordPress.org 允许插件注册短代码（Plugin Developer Handbook → Shortcodes），但不允许主题注册，所以配套主题一律使用页面模板。
* 连载默认关闭；关闭不会删除已有条目和设置。文章列表的「连载显示」列有四种状态：未启用 / 隐藏 / 默认显示 / 自动刷新，只有最后一种会轮询，且浏览器标签页隐藏时自动暂停。
* 「图片灯箱」选项输出带链接的图片标记；若 Simple Lightbox 已启用，还会经其官方 slb_activate() 主动激活——页面模板与小工具直接输出 HTML、不经过 the_content，必须显式激活才能加载灯箱主脚本。该插件仍不是依赖。

== 常见问题 ==

= 微博显示在哪里？ =
它们是独立内容类型。默认使用插件自带的「微博列表（插件）」页面模板；`[microblog]` 短代码、小工具、以及你设置的 URL 前缀归档页（默认 `/microposts`）都仍然可用，作为备选方式。

= 能修改微博的网址吗？ =
可以：「工具 → MicroBlog 设置 → 微博 → URL 前缀」。若链接出现 404，再保存一次「设置 → 固定链接」。

= 支持区块编辑器和任意主题吗？ =
都支持。内容类型跟随你的编辑器设置，样式与页面模板都由插件自带。KoneyGao 只额外提供可选的首页区块；插件模板在主题输出 `data-color-mode` / CSS 变量时自动跟随深浅色，其他主题回退到中性配色。在 KoneyGao 下可以用「微博List单页背景」开关关掉这套主题卡片外壳，回退成普通页面。

= 卸载会删除内容吗？ =
不会。`uninstall.php` 只删五个设置项，微博、连载内容、post meta 和 transient 都会保留，详见下一节。

= 连载模块需要 WP Cron 吗？ =
不需要。前端只对设为「自动刷新」的条目轮询，且标签页隐藏时跳过检查。

== 停用、卸载与数据清理 ==

1. 在插件列表页先「停用」；仅停用不会删除任何数据。
2. 再点击「删除」触发 `uninstall.php`。
3. 卸载脚本删除这五个 option：`microblog_micropost_data`、`microblog_general_data`、`microblog_liveblog_data`、`microblog_rewrite_signature`、`widget_microblog_widget`。
4. **刻意保留**：全部 `micropost` / `microlive` 条目、相关 post meta 与 transient —— 它们是你的内容，插件不会替你删除。
5. 若希望站点彻底干净，请先手动删除这些内容和 post meta，备份数据库后再执行卸载。

== 更新日志 ==

= 1.9.9 =
* 连载判定改为只查当前文章是否有条目，不再每次请求拉取全部连载条目并预热 meta；结果在单次请求内缓存。
* 删除快速发布提示遗留的死后台脚本与对应样式规则，并移除未使用的兼容别名函数。
* 区块编辑器保存锁由 40 次轮询改为一次 wp.data.subscribe() 监听；编辑器已被锁定时不再重复加锁。
* 微博小工具与短代码共用同一组设置/查询助手。
* 修复连载后台筛选选择「全部连载」时潜在的未定义变量分支。
* 重写规则不再每请求都读取完整的 `rewrite_rules` 选项做校验，只在插件激活、升级或影响规则的设置保存时检查；访问微博 URL 出现 404 时仍会触发一次自愈重建。
* 提升资源版本号，确保浏览器与 CDN 拉到新文件。

= 1.9.8 =
* 修复微博图片没有灯箱效果：「微博列表（插件）」页面模板与侧栏小工具直接输出 HTML，不经过 the_content；Simple Lightbox 只扫描 the_content，因此这些页面从未加载灯箱主脚本。开启「图片灯箱」后，图片 HTML 现在经官方 slb_activate() 主动激活，短代码、页面模板、小工具三条路径一致。
* 修复升级后微博归档页与详情页 404：除版本签名外，新增对已保存 rewrite 规则的校验。若规则里丢失 micropost 归档或 /slug/ID.html 规则（插件停用期间保存过「固定链接」、对象缓存回滚、部署时 flush 未写成功等），会自动重建；并用 5 分钟节流避免反复重建。
* 版本号提升会强制触发一次 rewrite 规则重建，已有 404 无需手动保存固定链接即可自愈。

= 1.9.7 =
* 区块编辑器的文档侧栏新增一行「连载原文：」，显示本条连载所属原文的标题并链接回原文编辑页。新建条目时读取 mlb_parent 查询参数，编辑既有条目时读取已保存的 _micro_live_post_id。纯只读渲染，不写数据库。
* 新增「Liveblog source:」中文文案并重新编译 .mo 语言包。

= 1.9.6 =
* 连载条目的微信分享卡片正文更长：旧写法用 wp_trim_words() 按「词」截断，中文整段被当成一个词，实际只截出约 40 字，正文区大半空着；现在按字符宽度提供足够素材，由主题的 5 行 line-clamp 兜底。
* 需与 KoneyGao 主题同步更新：主题分享卡片样式压缩了头部与留白、收紧标题与正文字号，让多出来的文字在卡片不增高的前提下排下。
